# Wending-Application

I created desktop application that helps to manage your vending machine all over the city.
This application interacts directly with database in SSMS
Instruction: before use the app you'll need SMSS and Visual Studio to assemble the project.
Firstly you need the connection string like this to connect to your database.
<img width="127" height="32" alt="image" src="https://github.com/user-attachments/assets/e57e4963-70e0-474e-8139-720d406d631d" />
After this you must insert it in your project (in JSON and in code) like here.
<img width="828" height="45" alt="image" src="https://github.com/user-attachments/assets/95cc3794-8325-4e4c-8cee-7deba0b9719d" />
You also need to download following dependecies via NuGet:
<img width="657" height="289" alt="image" src="https://github.com/user-attachments/assets/201b9126-8538-41e5-a694-110c109f2ebc" />
<img width="691" height="196" alt="image" src="https://github.com/user-attachments/assets/81ffe6b2-4a2c-4884-b952-5c39b8dfab4c" />
Execute the requests that in file "requests" in your database.
(important: all project files are in master branch)
